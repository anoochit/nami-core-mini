# Wiki Curator Skill Guidelines

When managing and maintaining wiki documentation:

1. **Folder Organization**: Group related topics into clean subdirectories under `wiki/` (e.g. `wiki/hardware/`, `wiki/rust-basics/`).
2. **Category Indexing**: Ensure every subfolder contains an `index.md` file listing all articles within that category.
3. **Master Index Maintenance**: Keep `wiki/index.md` updated with links and concise descriptions for all categories and primary documents.
4. **Document Formatting**: Use structured Markdown headers, bullet points, and specification lists for readable documentation.
